# BookFair Manager

An offline-first Flutter application for managing book fairs, inventory, investments, expenses, sales, and partner accounts.

### Key Features
- Book inventory and stock management
- Partner investment and expense tracking
- Sales, discounts, and profit calculations
- Cash and online payment tracking
- Dashboard and business reports
- PDF, Excel, and data export/import
- Local data storage using Hive

### Tech Stack
- Flutter & Dart
- Hive (Local Database)

**Note:** Currently operates entirely offline without a backend. Cloud synchronization is planned for future releases.
